# Llámame

Interruptor para Claude Code. Encima de la caja de chat aparece el botón «📞 Llámame». Activado, Claude sabe que no
estás mirando el chat: cuando necesite tu permiso o una decisión para seguir (borrar, publicar, gastar, elegir entre
caminos), te llama al celular con la habilidad `llamar-al-dueno` de la app Pendientes, lee lo que respondiste y sigue.
Para avisos te deja un mensaje en la app. También se activa o desactiva con `/llamame`. Queda guardado entre sesiones.

Requiere haber abierto antes `escritorio/Activar-llamadas-Claude.cmd` (instala la herramienta y la habilidad).
